Single-colour line icons exported from the Figma file "Wursor - weown.net" (Icon/* components).
Used through the `Icon` component (src/ui/Icon.tsx), which paints them with CSS masks so the colour comes from the
current theme. Do not edit the files; re-export from Figma if an icon changes.

Exception: `sun.svg` and `moon.svg` (theme toggle) are not Figma exports. They are hand-drawn to match the set (16px, 1.5 stroke, round caps). Replace them with the Figma Icon/Sun and Icon/Moon exports when those exist.
